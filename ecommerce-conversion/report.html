Key insights

  1. Overall conversion rate is 3.18% from 60,000 sessions, with an average order value of 78.67.
  2. Best channel: Email (6.19%). Weakest: Social Media (1.34%).
  3. Desktop converts at 4.99% vs Mobile at 2.14% (2.3x gap), although mobile brings 60.10% of the traffic.
  4. Returning users convert 2.8x better than new users.
  5. Peak month: Dec (4.61%). Lowest month: Feb (2.29%).
  6. Biggest funnel leak: Add to cart step (88% of visitors lost). Checkout abandonment is 45.82%.
  7. Largest opportunity: lifting 'User type: New' to the average would add about 480 orders (~37,787 revenue).

Recommendations

  • Fix mobile checkout: guest checkout, UPI / wallet payments, fewer form fields, bigger buttons.
  • Social media: use dedicated landing pages, retargeting and shoppable posts; judge it on assisted conversions too.
  • Email and returning users convert best: grow the email list, run cart-abandonment and win-back mails, add loyalty rewards.
  • New users: add trust signals (reviews, return policy, secure-payment badges) and a first-order offer.
  • Seasonality: plan stock, ad budget and server capacity before Nov-Dec; start campaigns in October.
  • Abandonment: show shipping and tax early, add exit-intent offers, send reminder emails within 1 hour.

Limitation: data is simulated, so the numbers illustrate the method, not a real business.
